# Persamaan Laju Reaksi dan Analisis Data (Kimia XI, Subbab 3)

Situs statis satu halaman. Tidak perlu build atau npm.

File: `index.html` (wajib berada di root repositori), `vercel.json`, `.gitignore`.

## Deploy
1. Ekstrak zip. Isi folder (index.html, vercel.json, ...) harus langsung terlihat, bukan di dalam subfolder.
2. Buat repositori GitHub, unggah SEMUA file tadi (Add file > Upload files), lalu Commit.
3. vercel.com > Add New > Project > Import repositori.
4. Framework Preset: Other. Root Directory: ./ . Build/Output/Install: biarkan kosong. Klik Deploy.

Jika muncul 404: buka Settings > General > Root Directory, pastikan kosong atau ./ , lalu Redeploy.
